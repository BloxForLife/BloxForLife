How your IP is secured

A plain-language explanation, no jargon

What gets logged

When you leave a note, this site stores your name, your message, and a scrambled ("hashed") version of your IP address. It's used for one thing only: stopping spam and repeat abuse. It's never shown publicly, sold, or used for anything else.

Why not just store the real IP?

Because it doesn't need to. A hash lets the site check "has this person already left a note recently?" or "is this a specific person I've blocked?" — without ever needing to know or store the actual address.

What's a hash, actually?

A hash is a one-way scrambling process. Your IP goes in, a fixed-length jumble of letters and numbers comes out — like a1b2c3d4e5f6a7b8. There's no formula to reverse it back into the original IP. The same input always produces the same output, so it's still useful for comparing "is this the same visitor as before?" — just without ever storing what that visitor's real address was.

The salt

There's a catch with hashing on its own: IPv4 has only about 4.3 billion possible addresses, so someone could theoretically pre-calculate the hash of every single one and build a lookup table to reverse it. To stop that, a private secret string (a "salt") gets mixed in before hashing. Without knowing that secret, a pre-built lookup table is useless — so the hash stays effectively unreversible.

Bottom line

Nobody — including the site owner — can look at a stored hash and figure out your real IP address from it. It only works to confirm "yep, that's the same visitor as before," which is exactly what it's needed for.
